# TA Live Demo Script — Insight Writing with GenAI
> Session 25 | Runtime: ~8 minutes | Delivered at session end, after Balaji's lecture

**Setup before class starts:** The Chennai -3% dashboard from Session 24 already open, plus a GenAI chat tool ready on the demo screen.

---

```
STEP 1 — Try the weak prompt first, on purpose (≈2 min)
  Action: Type into GenAI: "Write something about this Chennai
  chart."
  Result: a generic, vague paragraph that just restates "revenue is
  down slightly this month"
  Say out loud: "Fluent sentence. Almost no actual insight in it.
  This is exactly the trap from today's lecture — vague prompt,
  vague draft."
```

```
STEP 2 — Rewrite the prompt with the real reading included (≈2 min)
  Action: Type into GenAI: "Chennai's revenue is down 3% this month
  while Bengaluru, Hyderabad, and Pune are all up. The decline is
  specifically in the Groceries category, confirmed over a 3-week
  consistent trend, not a single-day blip. Write a 3-sentence
  insight for our founder explaining what this likely means and
  what to check next."
  Result: a specific, genuine insight paragraph naming Chennai,
  Groceries, and a concrete next step
  Say out loud: "Same tool. Same chart. The only thing that changed
  is I fed it my own confirmed reading from last session instead of
  just pointing at the chart."
```

```
STEP 3 — Fact-check the draft against the actual dashboard (≈2 min)
  Action: Re-open the Chennai dashboard and verify each claim in the
  GenAI draft — does it really say 3%? Is Groceries really the
  specific category? Is the trend really 3 weeks, not a guess?
  Say out loud: "This step is not optional. GenAI can sound
  completely confident and still get a detail slightly wrong or add
  something I never told it. I check every number against the real
  dashboard before this goes anywhere."
```

```
STEP 4 — Ask for a second tone variant (≈1 min)
  Action: Prompt GenAI: "Now rewrite that same insight in a
  collaborative, non-accusatory tone for the Chennai store team
  instead of the founder."
  Result: a softer version inviting collaboration rather than
  reporting a problem
  Say out loud: "Same underlying, fact-checked insight — two
  completely different tones for two different readers. That
  tone choice is still mine to make, not GenAI's."
```

```
STEP 5 — Pair the final text with the chart (≈1 min)
  Action: Place the fact-checked founder-facing insight text directly
  beside the Chennai revenue-by-city bar chart
  Say out loud: "Chart plus text, together. That's a complete data
  story — visual proof and plain-language meaning, in one place."
```

---

> **TA TALKING POINT:** "GenAI made this insight faster to write, not more true — the fact-check step I just did against the real dashboard is the one step you should never skip, no matter how confident the draft sounds."
