# TA Live Demo Script — Dashboard Design Basics
> Session 22 | Runtime: ~8 minutes | Delivered at session end, after Balaji's lecture

**Setup before class starts:** Two saved versions of the Session 21 Kirana365 dashboard open in separate tabs — "Version A" (cluttered: gridlines, repeated legend, every bar labelled, five accent colours, drop shadows) and a blank copy of the same dashboard to rebuild live into "Version B."

---

```
STEP 1 — Open Version A and let it speak for itself (≈1 min)
  Action: Display Version A full-screen
  Say out loud: "Quick gut check — hands up if this feels busy just
  looking at it, before I say another word."
```

```
STEP 2 — Turn off gridlines (≈1 min)
  Action: Right-click each chart → Format → Lines → Gridlines → None
  Result: charts immediately look calmer
  Say out loud: "Nothing was removed except visual noise — every
  number is still exactly where it was."
```

```
STEP 3 — Remove the redundant legend (≈1 min)
  Action: Right-click the City legend → Hide Legend (city names are
  already shown on the bars themselves)
  Say out loud: "This legend was repeating information already on
  the chart. Gone, and nothing is lost."
```

```
STEP 4 — Cut labels down to what matters (≈2 min)
  Action: Remove data labels from every bar, then re-add labels only
  to the highest and lowest bar
  Say out loud: "I don't need every single number staring at me —
  I need the story: who's highest, who's lowest. Everything else is
  one hover away in the tooltip."
```

```
STEP 5 — Reduce five colours to one purposeful colour (≈2 min)
  Action: Reset all bars to a single neutral colour, then apply a
  single accent colour only to the underperforming city (Chennai)
  Result: one clear visual flag instead of five competing colours
  Say out loud: "Now colour actually means something — it points
  straight at the one thing that needs attention."
```

```
STEP 6 — Reorder for the reader (≈1 min)
  Action: Drag the KPI tile to top-left, segment table just below it,
  detail charts underneath
  Say out loud: "Last move — nothing new added, just arranged in the
  order someone would actually want to read it."
```

---

> **TA TALKING POINT:** "Every single fix I just made was a removal or a rearrangement — not one new chart, not one new colour added. That's the whole lesson: good dashboard design almost always means taking things away, not adding them."
