# TA Live Demo Script — Dashboards That Support Decisions
> Session 23 | Runtime: ~9 minutes | Delivered at session end, after Balaji's lecture

**Setup before class starts:** The cluttered 12-chart "meeting that went nowhere" dashboard from the opening already saved, plus the Kirana365 Bengaluru ad-spend data (conversion rate by month, ad spend, revenue by month) available to build the trimmed version live.

---

```
STEP 1 — Show the 12-chart dashboard again (≈1 min)
  Action: Display the full 12-chart dashboard
  Say out loud: "Same dashboard from this morning's opening. Let's
  actually fix it, live, for one specific decision: should Kirana365
  increase the Bengaluru ad budget by ₹50,000?"
```

```
STEP 2 — Trim to only relevant charts (≈2 min)
  Action: Duplicate the dashboard, delete 9 of the 12 charts, keeping
  only: conversion rate trend, ROI comparison, and a revenue
  projection
  Say out loud: "Nine charts gone. Nothing about the business
  changed — I just stopped answering every possible question."
```

```
STEP 3 — Build and enlarge the headline insight (≈2 min)
  Action: Create a calculated field: [Revenue from Bengaluru Ads] /
  [Bengaluru Ad Spend], format as "₹4.20 return per ₹1 spent"
  Action: Resize this KPI tile to be the largest element on the page
  Say out loud: "This is the one fact that matters most for this
  decision. It should be impossible to miss."
```

```
STEP 4 — Sequence trend, evidence, ask (≈2 min)
  Action: Arrange top-to-bottom: (1) conversion rate trend line
  rising over 3 months, (2) the ₹4.20 ROI KPI compared to the
  company-wide ₹2.80 average, (3) a text box: "₹50,000 increase →
  projected ₹2,10,000 additional revenue next quarter"
  Say out loud: "Trend, then evidence, then the actual ask. By the
  third element, the reader has already reached the conclusion."
```

```
STEP 5 — Run the 15-second stranger test (≈2 min)
  Action: Flash the finished dashboard to a student who hasn't seen
  it and ask, "what decision is this dashboard arguing for?"
  Result: student correctly says "increase the Bengaluru ad budget"
  Say out loud: "That's the real test. If a stranger can't say the
  decision back to you in 15 seconds, the dashboard isn't done yet."
```

---

> **TA TALKING POINT:** "Before you present any dashboard for a real decision, ask yourself the same question I just asked a stranger in this room — can they tell me, in 15 seconds, what I want them to decide? If not, go back and cut, or enlarge, until they can."
